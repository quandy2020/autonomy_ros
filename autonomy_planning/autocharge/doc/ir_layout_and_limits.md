# 红外布局与物理限制

本文档描述当前 `autocharge` 使用的充电桩红外布局、机器人接收器布局、协议编码方式，以及这些约束对自动回充策略的直接影响。

## 1. 充电桩红外布局

当前充电桩在 `dock_frame` 下布置了 5 路红外发射器，沿横向从左到右依次为：

| 发射器 | 横向位置 y | 朝向 yaw | FOV | 模式 | 对应 token |
| --- | --- | --- | --- | --- | --- |
| `far_left` | `+14.25 mm` | `+20 deg` | `30 deg` | `normal` | `0x01` |
| `left` | `+6.0 mm` | `+5 deg` | `15 deg` | `normal` | `0x02` |
| `center` | `0.0 mm` | `0 deg` | `7.34 deg` | `trapezoid` | `0x04` |
| `right` | `-6.0 mm` | `-5 deg` | `15 deg` | `normal` | `0x08` |
| `far_right` | `-14.25 mm` | `-20 deg` | `30 deg` | `normal` | `0x10` |

布局特点：

1. `far_left` 与 `far_right` 的波束最宽，主要用于远距离与大偏差侧的首次捕获。
2. `left` 与 `right` 的波束较窄，主要用于从侧区向中心区过渡。
3. `center` 不是普通扇形，而是近场很窄的梯形波束，负责最后的居中与接触前确认。
4. 五束在近场存在明显重叠，因此边界区域会出现“同一接收器一次看到多路发射器”的现象。

## 2. 中心发射器的限制

`center` 发射器的配置与其他四路不同：

- `mode: trapezoid`
- `trap_length_m: 0.03`
- `trap_width_m: 0.002`
- `fov: 7.34 deg`

这意味着：

1. 在距发射器前方 `0 ~ 30 mm` 的近场范围内，中心束横向宽度仅约 `2 mm`。
2. 超过 `30 mm` 之后，才按 `7.34 deg` 向外扩张。
3. 机器人即使“看起来在正前方”，只要横向偏差略大，也可能暂时丢失中心束。

因此，最优策略不能要求机器人在进入中心区后一直稳定看到双边中心信号。策略必须允许：

- 短时间无信号；
- 单边中心或单边侧向信号；
- 依靠小角速度微调重新回到中心束。

## 3. 机器人接收器布局

机器人前方布置两路接收器，均安装在 `base_link` 前侧：

| 接收器 | x_offset | y_offset | yaw | FOV |
| --- | --- | --- | --- | --- |
| `left` | `0.16 m` | `-5.45 mm` | `-7.5 deg` | `15 deg` |
| `right` | `0.16 m` | `+5.45 mm` | `+7.5 deg` | `15 deg` |

这组安装方式带来几个约束：

1. 两个接收器间距约 `10.9 mm`，非常接近，但并不重合。
2. 两个接收器都位于车头前侧，因此对靠近接触阶段非常敏感。
3. 两个接收器都带有固定偏航角，意味着它们对同一发射器的可见范围不是完全对称的。
4. 接收器看到的是“接收器 FOV”和“发射器 FOV”的交集，而不是单侧几何关系。

因此，左右侧判定不能只靠“当前 token 包含了哪个 bit”，还必须参考：

- 是左接收器看到，还是右接收器看到；
- 当前是否为单边观测；
- 是否已经进入居中或 bias 阶段。

## 4. 协议编码限制

运行时 `DockIR.left` 与 `DockIR.right` 各自携带一个低 5 位编码。当前运行映射不是传统的“单 bit 单方向”模型，而是带有组合位与仿真布局耦合的编码。

当前仿真映射为：

| 发射器名 | 输出 token |
| --- | --- |
| `far_left` | `0x01` |
| `left` | `0x02` |
| `center` | `0x04` |
| `right` | `0x08` |
| `far_right` | `0x10` |

这里的关键限制是：

1. `0x10` 是 far_right 的独立 bit（不再使用组合位 `0x0F`）。
2. 边界区域中，一个接收器可能同时命中多路发射器，最终被编码为某个组合 token。
3. 因此，`(0x00, 0x10)` 与 `(0x10, 0x00)` 这类观测，物理意义首先是“单边可见”，其次才是具体 bit 语义。

## 5. 关键观测模式

以下观测模式对自动回充策略最关键：

| 观测模式 `(left, right)` | 物理意义 | 推荐区域语义 |
| --- | --- | --- |
| `(0x00, 0x00)` | 当前无可用红外 | `UNKNOWN` |
| `(0x00, 0x10)` | 仅右接收器看到右侧宽束 | `RIGHT` / `FAR_RIGHT` |
| `(0x10, 0x00)` | 仅左接收器看到左侧宽束 | `LEFT` |
| `(0x04, 0x00)` | 单边中心命中 | `CENTER` 候选 |
| `(0x00, 0x04)` | 单边中心命中 | `CENTER` 候选 |
| `(0x04, 0x04)` | 双边中心命中 | `CENTER` |
| `(0x08, 0x02)` | 近中心对齐组合 | `CENTER` |

注意：

- 单边中心命中不能立即当成失败；
- 单边侧向命中不能在 `CENTER` 阶段强制退回 `SEARCH`；
- `BIAS_LEFT` / `BIAS_RIGHT` 不能在一次扫描周期中途频繁切换，否则会在边界区震荡。

## 6. 自动回充的物理限制

基于当前红外布局，自动回充具备以下天然限制：

1. **不适合从任意远距离盲目直接进桩**  
   最优流程应先通过 `predock_pose` 或导航，将机器人送到桩前可观测区域。

2. **中心束对横向误差很敏感**  
   接近接触前，机器人必须用较小角速度和较低线速度推进。

3. **边界区会出现左右侧抖动**  
   单边可见区不是离散、干净的“左区/右区”，而是会来回闪烁。因此 bias 状态必须有锁边和阶段化执行策略。

4. **只靠距离无法可靠判定成功**  
   当前最可靠的成功条件只能是 `charge_connected`。距离和姿态只适合做统计、分析和调试。

## 7. 成功判定限制

当前回充成功严格由 `charge_connected` 触发。该信号来自仿真中的几何接触判断，核心含义是：

- 机器人前方 IR 参考点与充电桩中心 IR 的距离足够小；
- 横向误差足够小；
- 朝向误差足够小；
- 连续保持一段时间后，发布 `charge_connected = true`。

因此：

1. FSM 不应再使用几何距离直接跳转 `SUCCESS`。
2. `CENTER` 阶段的职责是“把机器人稳定送入可接触区域”，不是自己判定已经成功。
3. 文档、代码、日志都应统一以 `charge_connected` 作为最终成功标准。
