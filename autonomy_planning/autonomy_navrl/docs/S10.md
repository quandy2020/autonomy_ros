# S10 四足轮足指南

S10（`urdf/S10-urdf-2`）为 **16 DOF 轮足四足**。默认低层运控为 **`s10_gait`**（运动学步态：腿关节踏步 + 轮驱动），可选 `s10_stance_drive`（腿锁站姿）或 `s10_jit`（RL）。

## 快速流程

```bash
# 1. 准备 URDF（camera_link + IMU 惯性；force USD 重建）
bash scripts/navrl.sh setup s10 urdf

# 3. 运控冒烟（抬腿前进 / 横移 / 斜向）
bash scripts/navrl.sh demo-s10-loco -w --vx 0.3              # 纵移（抬腿 + 轮驱动）
bash scripts/navrl.sh demo-s10-loco -w --vy 0.25 --gait-mode strafe   # 横移（蟹步抬腿）
bash scripts/navrl.sh demo-s10-loco -w --vx 0.2 --vy 0.15    # 斜向
bash scripts/navrl.sh demo-s10-loco -w --gait-mode march      # 原地踏步

# 3. （可选）训练 JIT 低层速度策略
bash scripts/navrl.sh train-s10-loco --headless --num_envs 4096 --max_iterations 5000
```

## 运控后端

| backend | 说明 |
|---------|------|
| `s10_gait` | **默认**。对角/侧向抬腿步态 + 轮推进；`auto` 按速度选 stand/march/walk/strafe |
| `s10_stance_drive` | 腿锁站姿 + 轮驱动（精准对齐 demo 默认） |
| `s10_jit` | TorchScript RL（需匹配观测的 `weights/s10/policy.pt`） |

`gait.mode`: `auto` | `stand` | `march` | `walk` | `strafe`。

## 关节布局（与 s10_jit 一致）

| 腿 | 关节 |
|----|------|
| FL | fl_hipx, fl_hipy, fl_knee, fl_wheel |
| FR | fr_hipx, fr_hipy, fr_knee, fr_wheel |
| HL | hl_hipx, hl_hipy, hl_knee, hl_wheel |
| HR | hr_hipx, hr_hipy, hr_knee, hr_wheel |

**JIT 观测 57 维** / **动作 16 维**（12 腿位置 ×0.25 + 4 轮速度 ×5.0）。

```
imu_ang_vel*0.25(3) + imu_projected_gravity(3) + vel_cmd(3)
+ joint_pos_rel_no_wheel(16) + joint_vel*0.05(16) + last_action(16)
```

- 角速度 / 重力来自 **IMU**（`imu_link`，与 base 对齐）
- 轮关节相对位置在观测中 **强制为 0**（避免 continuous 角漂移）
- 训练奖励含 `flat_orientation_l2=-1.0`，抑制趴地

## URDF 适配要点

| 项 | 说明 |
|----|------|
| `base_link` COM | 仿真将 Y 偏置居中（原 y≈0.057 侧倾） |
| `imu_link` | 补惯性；`rpy=0` 与机身对齐（策略用 IMU 观测） |
| spawn z | `0.40`（轮触地约 0.37，略悬空落下） |
| 站姿 | hipy=0.67, knee=-1.30 |

## 配置 Profile

| Profile | 用途 |
|---------|------|
| `s10-jit` | 上层 PPO + 低层运控 |
| `s10-loco` | 运控冒烟（单 env，恒定速度） |
| `demo` | 精准对齐 + 目标可视化 |

## 精准对齐 demo

上层姿态跟踪器 + 低层 `s10_gait`（远距先弧线转向对准目标，再前进；近距轮式微调）。

侧向/斜向目标示例：

```bash
bash scripts/navrl.sh demo s10 -w -x 0 -y 4 --yaw 0
bash scripts/navrl.sh demo s10 -w -x 2 -y 2 --yaw 45
```

说明：S10 锁腿时几乎不能原地差速转向/横移，因此精准对齐默认用 `s10_gait`，并用「前进+转向」弧线接近，避免在侧方目标处卡死。

```bash
# headless
bash scripts/navrl.sh demo s10 --headless -x 1 -y 0 --yaw 0

# WebRTC（目标框 / 朝向箭头 / 容差圆）
bash scripts/navrl.sh demo s10 -w -x 1 -y 0 --yaw 0
```

画面中：目标 footprint + 朝向箭头/坐标轴、机器人 footprint + 朝向、位置容差圆。

## 诊断：hold-stance

不跑步态、只 PD 保持默认站姿。若能站稳，说明 URDF/执行器没问题：

```bash
bash scripts/navrl.sh demo-s10-loco --hold-stance -w --max-steps 500
```

成功时 `z≈0.36`、`grav_z≈-1`。

## 训练说明

任务 ID：`Isaac-Velocity-Rough-S10-v0`  
配置：`isaaclab_ext/s10_locomotion/`  
导出：`weights/s10/policy.pt`

速度跟踪续训（加强 `track_lin/ang`，降低站住比例）：

```bash
bash scripts/navrl.sh train-s10-loco --headless --num_envs 4096 --resume \
  --load_run 2026-08-12_10-25-16_s10_velocity_rough --checkpoint model_2999.pt \
  --max_iterations 2000
```

**不可**复用 Go2W 或旧版（无 IMU 缩放）的 `policy.pt`。
